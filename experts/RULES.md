# 专家组意见库 — 运行规则（v1.0，2026-10）

本目录是一个**可定期更新的"专家蒸馏知识库 + 虚拟专家组"**：追踪环境毒理学领域有影响力的学者，
定期纳入其最新文章，蒸馏其研究内容与学术思想，并以"专家组会议"的形式为本项目
（斑马鱼行为毒理学 / 新污染物研究）提供多视角意见。

---

## 1. 目标与定位

1. **蒸馏，不是存档**：不做全文收藏，不堆砌摘要。每位专家一份"档案"（profile），
   核心是提炼其**学术思想**（核心主张、方法论签名、范式演变）和**近期动向**，
   让读档案的人 10 分钟内能"像这位专家一样思考"。
2. **意见库，不只是文献库**：每份档案末尾必须有"专家视角 Persona"一节
   （该专家评审/讨论时的典型立场与常问问题），这是召开虚拟专家组会议的直接素材。
3. **服务于本项目**：每篇近期文章的蒸馏都要回答"对斑马鱼行为/发育毒理研究者的启示是什么"。

## 2. 目录结构

```
experts/
├── RULES.md              # 本文件：运行规则
├── ROSTER.md             # 现役名单 + 候选观察名单（含领域划分、纳入/退出记录）
├── profiles/             # 每位现役专家一个档案（文件名：拼音，如 zhou-bingsheng.md）
├── panel/
│   ├── HOW_TO_CONVENE.md # 如何召开虚拟专家组会议（流程与提示词模板）
│   └── discussions/      # 会议纪要（YYYY-MM-DD-主题.md）
└── updates/              # 每期更新简报（YYYY-MM.md：本期新纳入的文章、名单变动、趋势观察）
```

## 3. 专家档案规范（profiles/*.md）

统一模板（新建档案必须包含全部 7 节）：

1. **基本信息** — 单位、头衔、方向标签。
2. **学术思想蒸馏** — 2.1 核心主张（3–6 条）；2.2 方法论签名；2.3 研究范式演变。
3. **代表作精读** — 5–8 篇，可跨年代；每篇 2–4 句（发现 + 方法 + 为何重要）。
4. **近期文章蒸馏** — 滚动覆盖近 24 个月，时间倒序；每篇：
   标题 | 期刊 | 年份 | DOI；一句话核心发现；方法要点；**对本项目的启示**。
   每位专家保留 8–20 篇；超出时按重要性淘汰旧条目（移入档案末尾的"归档"小节或直接删除）。
5. **基金档案** — 该专家主持的科研项目（以 NSFC 为主，来源：科学基金共享服务网 output.nsfc.gov.cn、
   基金委官网、LetPub 等公开数据库）：项目题目/批准号/类别/年限清单；对已结题项目蒸馏其**结题摘要**
   （立项科学问题 → 实际完成与主要发现 → 与发表论文的对应关系）；并提炼"问题意识演变"
   （从早年到近年申请选题的变化轨迹，这是凝练学术思想的一手材料）。查不到的如实注明。
6. **趋势判断** — 该课题组下一步方向（2–4 条，注明推断依据）。
7. **专家视角 Persona** — 以该专家身份参加评审/讨论时的典型立场与常问问题（6–10 条）。
8. **元数据** — 建议检索式（PubMed / Consensus / Web 检索串 + NSFC 共享服务网查询方式）、信息源、最后更新日期、置信度与待核实项。

**模型分工（控费规则）**：检索、简卡、基金档案抄录等"搬运型"工作由轻量模型子代理执行
（默认 Sonnet，纯抄录可用 Haiku）；学术思想蒸馏（§2）、趋势判断（§6）、Persona（§7）
与专家组会议产出由强模型执行。既有 5 份档案补写"基金档案"一节时亦按此分工。

**引文纪律（最重要的一条）**：档案中出现的每一篇论文都必须来自真实检索结果
（标题、期刊、年份可核，尽量附 DOI）。禁止凭记忆补全引文；不确定的条目标注 `⚠️待核实`。
每次更新后抽查 2–3 条 DOI 是否真实可解析。

## 4. 名单管理（ROSTER.md + roster/）

### 4.0 两层结构

| 层级 | 规模 | 内容 | 存放 |
|---|---|---|---|
| **核心层**（深蒸馏） | 10–20 人 | 完整 7 节档案（见 §3），逐篇蒸馏近期文章 | `profiles/` |
| **扩展层**（简卡） | 100 人以上 | 每人一张"简卡"：方向标签、影响力依据、2–3 篇近作、入核心层建议 | `roster/`（按领域分文件） |

扩展层是核心层的蓄水池：月度更新时主要跟踪核心层；季度评审时从扩展层晋升
表现突出者入核心层（晋升即建完整档案），核心层产出停滞者降回扩展层。
深蒸馏按批推进，每期更新新建 3–5 份完整档案，逐步覆盖扩展层中的高优先级者。

### 4.1 领域划分（十大领域）

| 代号 | 领域 | 扩展层目标 |
|---|---|---|
| A | 水生毒理与模式生物（斑马鱼行为/发育/内分泌） | 10–14 |
| B | 新污染物筛查与环境分析化学 | 10–14 |
| C | 计算毒理 / NAMs / AI 方法学（QSAR、高通量、类器官） | 8–12 |
| D | 分子机制毒理（AOP、受体通路、表观遗传、神经毒理） | 10–14 |
| E | 环境组学 / eDNA / 效应导向分析 | 6–10 |
| F | 环境健康与医学（暴露组学、环境流行病学、生殖发育健康） | 10–14 |
| G | 环境化学与污染过程（迁移转化、界面、复合污染） | 8–12 |
| H | 风险评估与监管科学 / 环境观点与政策 | 6–10 |
| I | 经典奠基人物（领域范式的建立者，以国际为主） | 8–12 |
| J | 创新交叉（微塑料、纳米、抗性基因、气候-污染等新兴方向引领者） | 10–14 |

一人可属多领域，以主领域归档。国内学者为主体，D/F/I/C 等领域应有相当比例国际学者。
用户点名的专家直接入核心层，不受影响力门槛约束。

### 4.2 纳入标准（满足其一即可进入扩展层；满足两条以上为核心层候选）

1. 近 3 年以通讯作者身份在领域顶刊（ES&T、Water Research、EHP、Nature/Science 子刊等）发文 ≥ 5 篇；
2. 近 3 年有高被引论文（ESI 前 1% 或单篇年均被引 ≥ 50）；
3. 开创或引领了一个方法/概念（如某类 NAMs、某类污染物的发现）；
4. 其工作与本项目（斑马鱼行为毒理、新污染物）直接相关且质量公认。

### 4.3 退出/降级标准

- 连续 2 期更新（约 6 个月）无新的相关产出 → 降入观察名单；
- 方向漂移、与库定位不再相关 → 归档其档案（移至 profiles/ 下加 `archived-` 前缀），不删除。

### 4.4 名单评审

每季度（每 3 期月度更新）做一次名单评审：对照 4.2/4.3 处理晋升与降级，结果记入当期 updates/ 简报。

## 5. 定期更新机制

- **频率**：每月一次（配套的定时任务自动触发；也可随时手动说"运行专家库月度更新"）。
- **每期流程**：
  1. 按各档案"元数据"中的检索式，检索每位现役专家近 2 个月新文（PubMed + Consensus + Web）；
  2. 筛选：通讯/核心作者、与领域相关、有实质增量（纯会议摘要、更正不收）；
  3. 将入选文章蒸馏后插入档案第 4 节顶部；必要时修订第 2/5/6 节（思想与趋势是活的）；
  4. 写当期 `updates/YYYY-MM.md` 简报：各专家新文清单、跨专家的共同趋势（≥2 个组同时在做的事）、名单变动建议；
  5. 季度期加做名单评审（见 4.4）；
  6. 提交并推送，commit 信息格式：`experts: YYYY-MM monthly update`。
- **质量门槛**：宁缺毋滥。某专家当期无合格新文就明确写"本期无新增"，不得为凑数降低标准。

## 6. 虚拟专家组会议（panel/）

详见 `panel/HOW_TO_CONVENE.md`。要点：

- 任何实验设计、选题、投稿、审稿回复问题，都可"提交专家组讨论"；
- 每位相关专家的发言必须**锚定其档案**（引用其核心主张/Persona 条目/近期文章），不许泛泛而谈；
- 必须有交锋：主持人要主动挖掘专家间立场冲突（如计算毒理 vs 整体动物实验、环境相关浓度 vs 机制剂量）；
- 会议产出：共识、分歧（及其根源）、给用户的可执行建议清单；纪要存 `panel/discussions/`。

## 7. 边界与免责

- 档案是**基于公开文献的蒸馏与推断**，"专家视角"是模拟立场，不代表本人真实观点；
  对外引用时只引用原始论文，不引用本库的转述。
- 库内容仅供本课题组内部研究参考。
