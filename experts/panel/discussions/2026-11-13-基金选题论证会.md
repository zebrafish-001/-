## 1. 空白点扫描（主持人汇总全库 §6 趋势判断）

扫描 20 份深档案 §6 + `updates/2026-10.md` 五条跨领域趋势，得到四个"多组正在逼近、但尚无人占住"的空白点。

### 空白点 1：功能性终点里"心脏"是真空，而"行为"已经挤满
- 本库简报趋势 1 指出行为正成为 A/D/F/J 四册的共同终点：Tal 的 VAMR 行为指纹电池进入 OECD DNT 讨论（`tal-tamara.md` §6.1）、Tanguay 判断斑马鱼行为"2–3 年内会进入分层 DNT 策略指南性文件"（`tanguay-robyn.md` §6.1）、董光辉预期"引入斑马鱼高通量行为与成像"（`dong-guanghui.md` §6.3）。**行为赛道正在变拥挤。**
- 反观心脏：陈联国做 PFAS 心脏蛋白质组、DCOIT 心脏与晶状体（`chen-lianguo.md` §6.1–6.2），靳远祥 6PPD 心脏（`jin-yuanxiang.md` §6.2），周群芳做血液毒理（`zhou-qunfang.md` §6.2）——**全部停在分子/组织/蛋白层面，全库无一组做在体心功能（血流速度、射血时间、心电复极化）**。
- 判断：**"成鱼在体心功能"是本库范围内唯一无人占据的功能性终点**，且申请人已有 DFVS+iWorx 平台。这是"为什么是我们"的最硬答案。

### 空白点 2：亚畸形剂量下的"功能性损伤"没有被系统量化
- 史薇 §6.4 已公开质疑现行筛查假设（"Beyond Competitive Binding"，2025）；Villeneuve §6.1 把 tPOD 推向监管定量化；Escher §6.2 要求报告实测游离/细胞浓度；周炳升 §6.3 转向预测毒理与替代品设计。
- 四条线共同指向同一个未被回答的问题：**以形态畸形/致死为阈值的危害识别，是否系统性低估了功能性损伤？低估多少？**
- 全库没有任何一组把"形态学 POD / 转录组 tPOD / 功能学 POD（心电、行为）"三者在同一化合物同一暴露体系内对比过。

### 空白点 3：跨器官共享分子起始事件（MIE）
- Tal §6.2 的靶点反推已走到"钾通道/PPAR/GABA 等非经典靶点"（chlorophene→GABA-A/Kv7）；Tanguay §6.4 把 AHR 遗传易感性列为机制线核心增长点（2026 年 aip 三连发）。
- 但二者各自只落在一个器官。**"同一个 MIE 同时解释神经与心脏两个功能终点"的跨器官假说，全库无人提出。** 而 Kv7/KCNQ 家族恰好同时是神经元兴奋性与心肌复极化的决定因素（KCNQ1 即 LQT1 致病基因），AhR 激活与心脏发育毒性亦有经典二噁英证据链。

### 空白点 4：跨生命阶段的"早期指纹→慢性结局"定量外推
- 戴家银 §6.3 已形成"AOP+转录组+ML"稳定产线并预期纳入"行为、发育时序、能量代谢等非经典终点"；Villeneuve §6.1 的 tPOD 已覆盖五个类群；Tanguay §6.2 以 AI 做图像/行为/转录组分析。
- 但三者的 POD 都是**同一时点**的。申请人自建的 FTT 框架（早期多组学→慢性毒性轴→早期风险预测器）正是跨生命阶段，**全库无对标工作**。陈联国的"5 个月成鱼 + F1"设计（`chen-lianguo.md` §6.1）证明该暴露时长在技术上可行。

## 2. 候选题目三案

### 【主推】方案一：亚畸形剂量下的神经—心脏双功能毒性

**题目变体**（按锐利度递增；NSFC 题目宜 ≤30 字）
- A 稳妥版：《多卤代咔唑亚畸形剂量下的神经—心脏功能毒性及其机制》
- B 推荐版：**《多卤代咔唑亚畸形剂量下神经—心脏功能毒性的 AhR 依赖离子稳态重编程机制》**
- C 锐利版：《形态学无损、功能已损：类二噁英污染物跨器官功能毒性的剂量边界与共享机制》
  （C 版适合答辩型项目，函评中标题带冒号与判断句有风险，面上建议用 B）

**科学问题**：以形态畸形与致死为阈值的危害识别，是否系统性低估了类二噁英新污染物的危害——功能性损伤（心电复极化、运动与应激行为）是否在无可见畸形的剂量下已经发生，其剂量边界与共享机制由什么决定？

**科学问题属性**：② 聚焦前沿、独辟蹊径（备选 ④ 共性导向、交叉融通）

**核心假说**：PHCZs 经 AhR 激活这一已确立的 MIE，下游诱导离子通道与钙处理基因网络重编程（新的关键事件），在尚未出现形态畸形的剂量区间即同时导致心肌复极化异常与神经兴奋性改变；该"亚畸形功能毒性窗口"的宽度由卤素取代位置与数目决定。

**研究内容（四条）**
1. **功能毒性谱与三重 POD 对比**：同系物库（以 136-BCZ 等为核心，8–12 个同系物）剂量—效应，同体系内并行测定形态学终点（畸形率/致死，配合 `zebrafish-histopath-quant` 定量病理证明"无损"）、转录组 tPOD（`zebrafish-organ-tox` 器官归因）、功能学终点（幼鱼行为范式 + 成鱼 DFVS 多普勒与 iWorx 心电）；输出三类 POD 的比值（本项目的核心定量产出）。
2. **AhR 依赖性的因果验证**：ahr2 突变体/morphant + AhR 拮抗剂（CH-223191）救援实验，判定功能表型是否 AhR 依赖；辅以 `network-toxicology` 预测靶点与分子对接定位候选通道。
3. **离子稳态重编程这一关键事件的证据**：心脏钙处理与复极化相关基因/蛋白（kcnq1、kcnh6/zERG、ryr2、atp2a2 等）表达与定位，钙成像；药理工具双向验证（通道阻断剂加重、激活剂缓解）；建立"MIE→KE→两个 AO"的定量 AOP 片段。
4. **位置效应与类别管理规则**：`toxicophore-screening` 的 MMPA + 小样本 QSAR（嵌套 CV + SHAP + 适用域），得出卤素取代位置/数目与功能毒性窗口宽度的结构警示规则，服务新污染物按类管理。

**最小可行实验（4 个月内可完成，用于本子"工作基础"）**
- 单一化合物（136-BCZ，已有 RNA-seq）× 3 个亚畸形剂量 × 两个终点：幼鱼行为 + 成鱼心电；
- 目标是拿到一张"畸形率无显著差异、而 QT 或行为显著改变"的图。**这张图单独就能支撑整个立项依据。**

**最可能质疑它的专家与理由**

## 3. 交锋轮

**冲突轴一：行为终点的定位（机制主线 vs 筛查工具）**
- 刘春生立场（§6.4）：其组行为 assay 论文与专利均为方法学，机制型斑马鱼神经行为论文极少——他会主张行为只能做快速筛查与分类。
- Tanguay/Tal 立场（`tanguay-robyn.md` §6.1、`tal-tamara.md` §6.1）：行为指纹正走向可审计的监管级 NAM，VAMR 电池已进入 DNT 讨论，行为本身就是受监管认可的终点。
- **主持人裁决**：两方都对，但都不足以单独支撑本子。方案一的解法绕开了这场争论——**不靠行为做机制主线，而是让行为与心电两个独立功能终点收敛到同一个 MIE 上**。这既满足刘春生对"行为不能独撑机制"的保留，也吃到 Tanguay/Tal 所说的监管认可度。

**冲突轴二：剂量学（机制深度 vs 环境相关性）**
- 周炳升（§6.1、§2）与 Escher（§6.2）会从两侧夹击：一侧要环境相关浓度，一侧要实测游离浓度。
- 另一侧的现实约束：亚畸形剂量本来就比畸形剂量低，但是否能低到环境浓度量级，取决于 PHCZ 实际检出水平。
- **主持人裁决**：这是方案一最大的技术风险，必须在本子里正面写。做法：先用 `global-occurrence-figure` 把 PHCZ 实测浓度区间画出来，再据此设计剂量组；若最低功能效应浓度仍高于环境浓度 2 个数量级以上，立项依据必须改用"内暴露剂量对齐"（鱼体实测浓度 vs 人/野生鱼实测体负荷）而不是水浓度对齐，否则周炳升这条意见无法回应。

**冲突轴三：单一化合物 vs 混合暴露**
- Escher（§6.1–6.2 EBT/EBM、混合）与本库简报趋势 4（多因子交互与生态真实性）会质疑单化合物设计已在退场。
- 陈联国 §6.1 的反例：其组以"每年换一个终点、物种与暴露设计固定"的单化合物路线持续产出 ES&T 级论文。
- **主持人裁决**：本轮保持单化合物同系物库（位置效应需要结构变量干净），但在研究内容 4 末尾加一个"同系物等效混合物"验证组，用一个混合组回应趋势 4，成本极低。

**无冲突但需记录的合作窗口**
- 庄树林 §6.4：其 AI 平台终点含 BBB/神经毒性/DART/生态毒性，但**斑马鱼行为与心功能尚未纳入**，明确标注为"潜在空白与合作窗口"。方案一的功能毒性数据正是其平台缺的训练标签——可作为本子"国内外合作"一栏的实质内容。
- 陈联国 §6.2：DCOIT 的 Target 1/2 新合成化合物 + 器官 AOP 路线，与方案一的"位置效应→结构警示"方法论同构，是可引用的国内先例（亦为潜在竞争者，需留意）。

## 4. 三栏结论

### 共识
1. **成鱼在体心功能（Doppler+ECG）是申请人在本库 110 人范围内的唯一无人占据的终点**，必须作为本子的辨识度核心，不能只当附加终点写。
2. **"亚畸形剂量下的功能性损伤"是一个真问题**，且四条独立趋势线（史薇的筛查范式批判、Villeneuve 的 tPOD、Escher 的实测剂量、周炳升的预测毒理转向）都在逼近它而无人正面量化。
3. **双功能终点收敛于同一 MIE** 的设计，是回应"行为不能独撑机制"这一质疑的最经济解法。
4. 转化产物方向（方案二）在没有分析化学合作的情况下不可作主线。

### 分歧（及根源）
1. **剂量学能否满足环境相关性**——根源是 PHCZ 实测环境浓度本身偏低，与"亚畸形功能效应浓度"之间的差距尚未核实。**这是本次会议未能解决的问题，必须由申请人用实测数据先行确认。**
2. **AhR 依赖这条机制线的创新性**——Tanguay §6.4 正在把 AHR 易感性做成其核心增长点（2026 年 aip 三连发），以 AhR 为 MIE 存在"用新化合物重复已知机制"的函评风险。根源是 AhR→心脏毒性有庞大的二噁英经典文献。**对策：创新点必须明确落在 KE→AO 这一段（离子稳态重编程 + 功能性 POD 边界），而不是落在 MIE 上。本子里要写明"AhR 激活是已知前提，不是本项目的创新声称"。**
3. 单化合物 vs 混合，经裁决后降级为写法问题，不再是实质分歧。

### 给申请人的可执行建议（按优先级）
1. **【最高优先，4 个月内】做出那张关键图**：136-BCZ × 3 个亚畸形剂量，畸形率无显著差异而心电（QT）或行为显著改变。这张图是整个立项依据的支点，没有它，本子只是设想。
2. **【高】核实 PHCZ 实测环境浓度区间**，用 `global-occurrence-figure` 出一张图，据此定剂量组。若差距 >2 个数量级，立即切换为内暴露剂量对齐的叙事。
3. **【高】确认背景三项（本纪要 §0 的 A/B/C）**，特别是 ES&T 2026 的归属与申报类型。
4. **【中】题目用 B 推荐版**；科学问题属性填 ②；创新点按"KE→AO 段 + 功能性 POD 边界 + 位置效应规则"三条写，不要把 AhR 写成创新点。
5. **【中】在"国内外合作与交流"一栏写入庄树林方向的合作意向**（其 AI 平台缺斑马鱼行为/心功能标签），这是实质性而非客套的合作点。

## 5. 主推方案的本子骨架（面上 4 年；青年裁剪见括注）

**立项依据五段式**
1. 新污染物治理行动与类二噁英 PHCZs 的环境检出现状（引 `global-occurrence-figure` 的实测数据 + 江桂斌 §6.2 新污染物类别扩军的判断）；
2. 现行危害识别以形态/致死为阈值，史薇 2025 年已公开质疑筛查假设（§6.4）、Villeneuve 正把 tPOD 推向监管定量化（§6.1）——**阈值设定问题已被提出但未被量化**；
3. 功能性终点的监管地位正在确立：Tanguay 判断斑马鱼行为 2–3 年内进入分层 DNT 指南（§6.1）、Tal 的 VAMR 已进入 OECD 讨论（§6.1）——**但心功能缺位**；
4. 已有的 PHCZ/AhR 证据链（申请人 136-BCZ RNA-seq 预实验 + 二噁英心脏毒性经典文献）支持跨器官共享 MIE 的可能性；
5. 由此提出本项目的科学问题与假说。

**技术路线主干**：同系物库 → 形态/转录组/功能三重终点并行 → 三类 POD 比值 → ahr2 遗传与药理双重救援定因果 → 离子稳态 KE 证据 → MMPA/QSAR 出结构警示规则 → 定量 AOP 片段与类别管理建议。

**工作基础（按 §0-A 的确认结果二选一）**
- 若 ES&T 2026 为本人成果：以该文 + 136-BCZ RNA-seq + Doppler/ECG 与定量病理平台 + 已开源的分析工具链为四条基础；
- 若非本人成果：以 136-BCZ RNA-seq + 两套功能学平台 + 已在三类化合物（NBFR/PHCZ/阿维菌素）上跑通的筛查管线为三条基础，并注明工具链已开源可复现。

**进度安排（4 年）**
- 第 1 年：同系物库剂量—效应与形态学 POD；成鱼暴露批次启动；环境浓度核实。（青年 3 年：压到 4–6 个同系物）
- 第 2 年：转录组 tPOD 与器官归因；幼鱼行为 + 成鱼心电功能 POD；三重 POD 对比成文（第一篇）。
- 第 3 年：AhR 依赖性救援 + 离子稳态 KE 机制（第二篇）。
- 第 4 年：位置效应 QSAR 与结构警示规则 + 等效混合物验证组 + 定量 AOP 片段（第三篇）。（青年删此年，研究内容 4 降为讨论）

**创新点三条**（措辞直接可用）
1. 首次在同一暴露体系内对比类二噁英污染物的形态学、转录组与功能学三类效应阈值，定量给出以形态终点为阈值对危害的低估幅度；
2. 提出并验证"同一分子起始事件经离子稳态重编程同时导致心脏与神经两个功能性不良结局"的跨器官假说；
3. 建立成鱼在体心功能（脉冲多普勒+表面心电）作为新污染物功能性危害终点的测定与质控方法，并给出可用于类别管理的结构警示规则。

**风险与对策**
- 成鱼暴露周期长、存活率风险 → 第 1 年即启动暴露，幼鱼终点先行成文；
- 功能效应浓度远高于环境浓度 → 切换内暴露剂量对齐叙事（见 §3 冲突轴二）；
- AhR 依赖性为阴性（功能表型不依赖 AhR）→ 这是**阳性科学结果而非失败**，改写为"存在 AhR 非依赖的功能毒性通路"，本子风险一栏应如此明写，函评会认为申请人想清楚了。
